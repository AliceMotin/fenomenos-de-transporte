# Simulador de Engenharia Hidráulica
Aplicação desenvolvida em Python para simulação de sistemas hidráulicos, com foco em perda de carga, NPSH e análise de escoamento interno.

Projeto criado para a disciplina de Fenômenos de Transporte.

## Funcionalidades
- Cálculo de perda de carga (Darcy-Weisbach)
- Cálculo do Número de Reynolds
- Fator de atrito:
  - Haaland
  - Colebrook (iterativo)
- Perdas localizadas (coeficientes K)
- Linha piezométrica e linha de energia
- Cálculo de NPSH (análise de cavitação)
- Diagrama de Moody
- Calculadora baseada na Equação de Bernoulli

## Tecnologias Utilizadas
- Python 3
- PySide6
- Matplotlib
- NumPy
